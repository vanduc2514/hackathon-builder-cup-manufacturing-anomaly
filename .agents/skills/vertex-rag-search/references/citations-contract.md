# Vertex AI Search & RAG Citation Contract

In Kaizen Agent, RCA findings and repair recommendations are safety-critical. Uncited LLM hallucinations in manufacturing can cause catastrophic machine damage or safety incidents.

## Citation Schema Contract

All RAG responses generated by knowledge retrieval tools must adhere to the standard `CitationReference` schema:

```python
class CitationReference(BaseModel):
    document_id: str      # e.g., "manual_cnc_fanuc_02.pdf"
    title: str            # e.g., "Fanuc 31i Spindle Maintenance Manual"
    page_number: int | None # e.g., 112
    section: str | None   # e.g., "Section 4.3: Spindle Bearing Replacement"
    snippet: str          # Verbatim excerpt from document
    relevance_score: float # 0.0 - 1.0 confidence score
```

## Citation Formatting in Agent Outputs

Every finding written to the Blackboard by `root_cause.py` or spoken by `technician_copilot.py` must explicitly cite its backing source:

- **Correct**: *"According to CNC Maintenance Manual p. 112, high vibration (RMS > 4.5 mm/s) accompanied by 85°C bearing temperature indicates spindle bearing wear."*
- **Incorrect**: *"The machine is vibrating because bearings usually wear out after 5,000 hours."* (Lacks source attribution).

## Local Knowledge Base Layout

Documents for local indexing and mock search follow this directory layout:
- `manuals/`: PDF machine operating and maintenance manuals.
- `past_8d_reports/`: Historical resolved incident reports and countermeasures.
- `expert_videos/`: Extracted procedural SOP transcripts.
