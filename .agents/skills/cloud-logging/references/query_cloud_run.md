# Querying Cloud Run Logs in Cloud Logging

Cloud Run produces two streams of logs:
1. **Request Logs**: Automatically generated by Google's front-end proxy (`logName=~"cloudaudit.googleapis.com"`, HTTP status code, latency, user agent).
2. **Container Application Logs**: Written to `stdout` and `stderr` by FastAPI and Python logging (`import logging; logger = logging.getLogger(__name__)`).

## Identifying Cloud Run Resources

- **Resource Type**: `cloud_run_revision`
- **Key Labels**:
  - `resource.labels.service_name`: The name of the Cloud Run service (e.g. `kaizen-backend`).
  - `resource.labels.location`: Region (e.g. `asia-southeast1`).
  - `resource.labels.revision_name`: Specific deployment revision.

---

## Practical LQL Query Recipes

### 1. HTTP 5xx Server Errors
```lql
resource.type="cloud_run_revision"
AND resource.labels.service_name="kaizen-backend"
AND httpRequest.status>=500
```

### 2. Slow Requests (> 2 seconds latency)
```lql
resource.type="cloud_run_revision"
AND resource.labels.service_name="kaizen-backend"
AND httpRequest.latency > "2s"
```

### 3. Asynchronous Agent Exceptions & Stack Traces
```lql
resource.type="cloud_run_revision"
AND resource.labels.service_name="kaizen-backend"
AND severity="ERROR"
AND (textPayload=~"Traceback" OR jsonPayload.message=~"Traceback")
```

### 4. Server-Sent Events (SSE) Stream Activity
```lql
resource.type="cloud_run_revision"
AND resource.labels.service_name="kaizen-backend"
AND httpRequest.requestUrl=~"/api/incidents/stream"
```

### 5. Filter by Execution Environment
```lql
resource.type="cloud_run_revision"
AND resource.labels.service_name="kaizen-backend"
AND jsonPayload.app_env="production"
```
